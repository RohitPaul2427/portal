2. Phase-by-Phase Implementation & Feature Breakdown

Phase 1: Discovery, Codebase Map & Security Audit

  • Identified critical IDOR on /api/documents/download/{id} and /api/documents/view/{id}.
  • Identified horizontal privilege escalation where case managers could view any case across the company.
  • Detected plaintext client passwords returned in sales approval API responses.
  • Documented flat data structure limitations preventing concurrent Subclass 189/190/491 EOIs.

Phase 2: Data Architecture & Non-Destructive Schema Migration

  • Defined structured entities: CASE_APPLICATIONS, CASE_ACCESS_GRANTS, and CREDENTIAL_VAULT.
  • Created idempotent migration script: backend/migrations/case_workspace_v1_migration.py supporting dry-run and apply modes.
  • Preserved 100% backward compatibility for all existing fields and collections.

Phase 3: Central Authorization & IDOR Elimination

  • Engineered CaseAccessService (backend/core/case_access_service.py) implementing deny-by-default access control.
  • Validates client ownership, case manager assignment, active temporary grants, and admin roles.
  • Protected routes in documents.py, cases.py, deadlines.py, doc_expiry.py, and step_documents.py.
  • Removed plaintext passwords from sales and mini-portal response payloads.

Phase 4: Document Security & Ephemeral Watermarked Preview Engine

  • Built DocumentSecurity (backend/core/document_security.py) generating 15-minute cryptographically signed preview tokens.
  • Engineered dynamic visual watermarking for PDFs (via pypdf) and images (via Pillow) embedding viewer email, timestamp, IP, and case ID.
  • Preview endpoint: /api/case-workspace/{case_id}/documents/{doc_id}/preview-stream?token=....

Phase 5: Multi-Application Case Workspace & Credential Vault

  • Implemented multi-application register supporting concurrent Skills Assessments, EOIs, State Nominations, and Visa Lodgements without overwriting data.
  • Automated sensitive identifier masking (DHA-********5432) with audited reveal requests (/reveal-identifier).
  • Engineered AES-256 GCM Credential Vault (vault_service.py) encrypting government portal logins at rest with audited cleartext checkout.
  • Implemented temporary access grants preventing staff self-elevation and supporting instant revocation.
